## Core Logic (30-second version) / 核心逻辑（30秒版）

1. **Get the facts straight.** Separate facts from guesses. Check your own bias.
   搞清事实。区分事实和猜测，检查自己的预设立场。

2. **Find the principal contradiction.** Not all problems are equally important. Use three tests: counterfactual, leverage, root-cause.
   找主要矛盾。不是所有问题都同等重要。三测试：反事实、杠杆、根源。

3. **Test on a small scale.** Don't go all-in before validation.
   小范围验证。别一上来就 all-in。

4. **Concentrate forces on one point.** 60%+ resources on the main attack. Set deadlines.
   集中兵力打一个点。60%资源给主攻，设 deadline。

5. **Form your own judgment.** With confidence level. No empty slogans.
   形成自己的判断。带置信度，不空喊。

## The Seven Steps / 七步流程

| # | Name / 名称 | Core idea / 核心 |
|---|---|---|
| 1 | Investigation / 调查研究 | Facts vs. guesses; check presuppositions |
| 2 | Contradiction Analysis / 矛盾分析 | Principal contradiction (3 tests); nature; transformation |
| 3 | Practice Theory / 实践论 | Judgment → pilot → feedback → revise; set cycle rhythm |
| 4 | Strategy & Tactics / 战略战术 | Strategic confidence + tactical caution; stage positioning |
| 5 | Concentrate Forces / 集中兵力 | One breakthrough point; 60/30/10 allocation; deadlines |
| 6 | Mass Line / 群众路线 | Seek feedback; actively invite opposing views |
| 7 | Independence / 独立自主 | Final judgment + action plan + confidence level |

## Design Philosophy / 设计理念

- **Skeleton + Depth separation.** SKILL.md is a lightweight skeleton (~110 lines); all depth lives in one reference file. Easy to maintain.
  骨架与深度分离。主文件轻量，深度内容集中在一个参考文件，修改只改一处。

- **Trimming over completeness.** Four modes ensure you don't over-analyze simple problems.
  裁剪优先于完整。四种模式确保简单问题不过度分析。

- **Anti-patterns as guardrails.** 6 core (structural logic errors) + 6 extended (execution habits).
  反模式作为护栏。6条核心（结构性逻辑错误）+ 6条扩展（执行习惯）。

- **Method is the boat; leave it after crossing the river.**
  方法是船，过了河就放下。
